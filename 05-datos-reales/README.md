# 05 — Integración con datos reales

Herramientas conectadas a fuentes de datos reales en lugar de diccionarios hardcodeados.

## Fuentes de datos
- `data/alimentos.csv` — base de datos nutricional local
- `data/progreso.json` — registro persistente de comidas del usuario
- API externa — ejercicios con fallback local

## Ejecución
```bash
uv run nutrifit_bot.py
```
