# 02 — Aplicaciones completas

Dos aplicaciones conversacionales con flujos orquestados de múltiples pasos.

| Archivo | Descripción |
|---|---|
| `menu_planner.py` | MenuBot — planificador de menú semanal (9 pasos) |
| `gym_assistant.py` | GymBot — rutinas de gym personalizadas (12 pasos) |

## Ejecución

uv run menu_planner.py
